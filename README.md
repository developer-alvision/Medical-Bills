# Medical-Bills

Static hospital and pharmacy bill-management preview.

## Run locally

Open `index.html` in a browser. OCR, PDF, and spreadsheet libraries load from public CDNs, so those features require an internet connection.

## Deploy to Vercel

Import this repository in Vercel, select **Other** as the framework preset, leave the build command empty, and deploy the project root.

## Important

This preview stores records in the current browser only. It has no production authentication, shared database, or cross-device sync. Use synthetic or redacted bills; do not store real patient information in this preview.
